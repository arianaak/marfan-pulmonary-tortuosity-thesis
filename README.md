# Automated 3D Pulmonary Artery & Vein Segmentation and Vascular Tortuosity Quantification in Marfan Syndrome

Bachelor's Thesis Repository — West University of Timișoara (UVT)

## Repository Structure
- `literature/pdfs/` — Curated core bibliography (11 papers covering Marfan tortuosity biomarkers, 3D U-Net/nnU-Net/MONAI architectures, `clDice` topology loss, and HiPaS/PARSE2022/AirRC datasets).
- `literature/notes/` — Editable source relevance matrix (`thesis_source_relevance_notes.xlsx`) mapping extracted concepts and formulas to thesis chapters.
- `thesis/references.bib` — BibTeX bibliography for LaTeX compilation.
- `src/` — Segmentation pipeline (PyTorch / MONAI) and 3D centerline tortuosity quantification scripts (`DM`, `ICM`, `SOAM`).
